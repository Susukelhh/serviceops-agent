# 第 22 步学习记录：五层 Agent 架构

## 我现在应该先记住什么

- 架构图首先回答职责与数据流，不是把所有类名摆在一张图上。
- ServiceOps Agent 可以压缩成五层：角色入口、接入安全、LangGraph、执行数据、工程治理。
- LangGraph 决定“下一步去哪”，工具决定“现实中做什么”，数据库保存“进度、事实和证据”。
- 同一个 PostgreSQL 实例可以承载多类表，但 Checkpoint、业务记录和审计事件的语义不能混淆。
