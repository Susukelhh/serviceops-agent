# 第 21 步学习记录：用证据链演示 Agent 项目

## 我现在应该先记住什么

- 项目演示不是按文件目录念技术名词，而是按“业务问题 → Agent 决策 → 确定性执行 → 安全边界 → 可验证证据”展开。
- 五分钟只需要四个场景：订单工具、RAG 引用、越权隐藏、人工审批恢复。
- Checkpoint 回放展示工程执行轨迹，不展示模型隐藏思维原文。
- 面试现场承认本机 Docker 与真实生产平台的差距，比夸大“企业级”更可信。

## 本步真实完成

- 一键启动器可以校验 Compose、构建并等待容器、运行真实冒烟、打印短期身份并打开控制台。
- 启动器不会调用千问，不会自动批准写操作，也不会把 Token 写入报告。
- 三个单元测试覆盖完整成功、快速复检和 Docker 失败立即停止。
- 五分钟 Runbook、排障表、短课和一页式速查卡已经进入项目。
