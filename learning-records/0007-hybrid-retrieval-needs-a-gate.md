# 学习记录 0007：混合召回不是接上就算优化

## 我现在能说清楚什么

完整混合召回让向量和 BM25 分别查完整知识库，再用 RRF 合并名次；它和“只在向量候选里做 BM25 重排”
不是一回事。前者有能力新增关键词候选，后者只能调整已有候选顺序。

## 这次真实学到的边界

- 开发集 Top-1 从纯向量 83.87% 提升到 93.55%；
- 相对旧候选重排只增加 1.61 个百分点，不应夸大；
- Recall@5 没有提升，关键词救回数为 0，因为当前小语料纯向量已经全部召回；
- 新锁定集 FPR 50%，最终没有晋级，说明检索排序不能代替意图/范围判断。

## 面试时避免的错误

不能说“用了 Qdrant + BM25 + RRF，所以召回率提升”。应该说清楚问题、对照、指标、Bad Case 和是否晋级。
失败实验也是解决问题能力的证据，只要没有隐瞒失败或反复偷看 holdout 调参。

## 下一步问题

确定性正则能便宜地拦截已知天气/写诗表达，但面对“有雨吗”“考试作文”等语言漂移会漏判。下一步要把
意图分类单独做成版本化开发集、锁定集和混淆矩阵，再决定是否引入千问分类或“规则优先 + 模型兜底”。
