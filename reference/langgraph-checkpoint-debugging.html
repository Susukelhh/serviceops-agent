LangGraph Checkpoint 调试速查

State = 当前工作单；Checkpoint = super-step 边界的工作单快照；thread_id = 一组快照的档案袋编号。

StateSnapshot 字段

字段白话本项目用途
values当前全部状态字段白名单后展示当前状态并计算差异
next接下来要去的节点解释条件边结果；空元组表示结束
config快照与线程编号读取 checkpoint_id 和 thread_id
metadata快照来源与步数展示 source 和 super-step
created_at拍照时间按时间解释执行顺序
parent_config上一张照片展示父 checkpoint_id
tasks待执行任务识别节点错误与任务上的 interrupt
interrupts暂停说明证明退货写工具前已经暂停

常用 API

graph.aget_state(config)异步读取线程最新快照
graph.aget_state_history(config)异步读取历史；官方返回最新快照在前
Command(resume=value)使用同一 thread_id 从 interrupt 继续

面试提醒

  • Checkpoint 边界是 super-step，不要绝对化为“一节点一快照”。
  • 工程轨迹不是隐藏思维链；展示结构化结论、工具观察和真实 next。
  • 应用层优先使用公开状态 API，不直接依赖 Checkpointer 私有表。
  • 生产调试必须做权限、脱敏、保留期限和环境关闭门。
