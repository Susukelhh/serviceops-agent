第25步：问题不是“技术不够多”，而是低阈值让所有域外问题都获得证据。

请求 → 业务范围门 → Embedding → Qdrant阈值 → Top-K → 引用回答

纯阈值为何失败

阈值RecallFPR
0.10100%100%
0.2545.8%12.5%
0.3020.8%0%

范围门结果

  • 开发集 Recall：100%
  • 开发集 Decision：75% → 100%
  • 开发集 FPR：100% → 0%
  • 锁定集 Decision：100%，FPR：0%

解决了什么

  • 域外高词面重合误召回
  • 内部规则和凭据索取
  • 无意义Embedding调用
  • 控制台可解释拒绝事件

没有解决什么

  • 锁定集Top-1仍为75%
  • 同义表达语义召回能力
  • 开放世界所有域外说法
  • 真实线上分布与模型漂移

面试一句话

我先扫描阈值，发现FPR降到0会让Recall从100%跌到20.8%，所以在Embedding前加入高精度业务范围门；开发集FPR从100%降到0且Recall不变，12条锁定集也通过，但Top-1仍只有75%，因此下一步单独做排序实验。
