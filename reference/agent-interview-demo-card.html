ServiceOps Agent 演示速查卡

五分钟 · 四场景 · 一条主线

主线：模型负责有限决策，工具负责确定性行动，LangGraph 负责流程和恢复，PostgreSQL 负责共享状态，人工负责高风险写入。

开场公式

业务问题 → Agent 决策 → 确定性执行 → 安全边界 → 可验证证据

演示顺序

  1. SO100001：订单工具 + 9个 Checkpoint
  2. 发票税号：公共知识 RAG + Citation
  3. SO200001：JWT 身份绑定 + 越权隐藏
  4. SO100002：interrupt + reviewer + audit

页面证据

  • intent / confidence
  • planned_tool_call / tool_result
  • execute_order_tool
  • checkpoint_id / next / interrupt
  • 引用标题、版本、生效日期

四个追问

  • 为什么不是普通 Chain？——有环、暂停、恢复。
  • Checkpoint vs 业务表？——进度 vs 事实。
  • 为什么不展示 CoT？——不可靠且会泄密。
  • 为什么四种 Token？——职责分离与最小权限。

不要夸大

  • 本机双实例 ≠ 完整云生产集群
  • Hash Embedding ≠ 线上最终召回方案
  • 离线 P95 ≠ 千问生产 SLA
  • Docker 默认演示不调用付费模型

现场失败时

  • 先说清失败边界，不关闭 JWT 强行演示。
  • 展示第13步评测与第14步千问报告。
  • 展示 Checkpoint、架构与恢复演练证据。
  • 说明下一步排查顺序，而不是猜原因。
