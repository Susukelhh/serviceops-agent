Agent工具安全边界速查

模型负责提出“查哪个订单”；系统负责决定“以谁的身份查、是否允许查、结果能否返回”。

参数所有权

数据控制方本项目实现
用户自然语言不可信用户user_message
订单号用户/模型候选Pydantic格式校验
当前用户身份可信系统闭包注入，不进入Tool Schema
订单归属业务仓库get_for_user强制检查
用户回答确定性代码从结构化工具事实生成

最小安全链

Schema校验 → 身份注入 → 权限检查 → 工具执行 → 输出校验 → 安全文案 → 审计事件。

防止数据枚举

“订单不存在”和“订单属于其他用户”必须使用相同失败结果，否则攻击者可以通过响应差异枚举有效订单号。
