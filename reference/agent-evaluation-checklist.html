数据集最小字段

  • 稳定 case_id 与显式 version
  • 输入和可信系统身份分开
  • Reference 不传给被测 Agent
  • Required 与 Forbidden 同时覆盖
  • 常见路径、边界、故障、安全负例都要有

指标解释

  • Accuracy：分母和样本类型必须一起报告。
  • Overall：一条样本所有关键维度通过才计入。
  • P95：先固定机器/预热/重复次数，再设硬门。
  • 100%：只能描述当前数据集与配置，不能外推生产。
