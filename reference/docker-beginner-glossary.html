Docker 白话术语表

第一次遇到专业词时先看“白话解释”，暂时不需要背完整定义。

术语白话解释ServiceOps 示例
Docker负责制作和运行标准化程序包装的工具让 Agent 离开 PyCharm 也能按同样方式启动
Dockerfile制作包装的说明书规定 Python 版本、依赖和启动命令
镜像 Image做好但尚未运行的程序模板serviceops-agent:local
容器 Container镜像启动后正在运行的一份程序当前正在营业的 Agent API
Compose一次管理一组容器及其配置的清单compose.yaml 规定端口、数据库卷和运行环境
端口 Port程序对外提供服务的窗口编号浏览器通过 8000 找到 Agent
数据卷 Volume独立于容器的长期存储柜保存 Checkpoint 和业务 SQLite 文件
Build根据说明书制作镜像docker compose build
Up启动容器docker compose up
Down停止并移除容器默认保留数据卷，不等于删除业务数据
Health check定期检查程序是否能正常接待请求访问 /ready 检查四个依赖
最重要的区别：镜像是“模板”，容器是“模板启动后正在运行的一份实例”，数据卷是“容器关掉后仍然保留的档案柜”。
