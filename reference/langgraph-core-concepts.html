LangGraph 核心概念速查

对应 ServiceOps Agent 第一步代码。先掌握状态如何流动，再学习模型和工具。

概念一句话解释项目对应位置
State一次任务在节点之间共享的数据结构。graph/state.py
Node读取当前状态并返回部分状态更新的函数。graph/nodes/
Edge声明一个节点完成后应前往哪里。graph/builder.py
Conditional Edge根据状态动态选择下一条路径。graph/routes.py
Reducer定义同一状态字段接收多次更新时如何合并。events: Annotated[..., add]
Compile校验图结构并生成可执行对象。builder.compile()

节点的核心约束

节点返回状态增量，不直接修改一个进程级全局字典。这样更容易测试、追踪、重试和恢复。

本阶段安全默认值

分类证据不足时进入人工路径。企业 Agent 的目标不是永远给出回答，而是在不确定时安全退出。
