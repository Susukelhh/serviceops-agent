====================================================================================================
27. 从头读代码的推荐路线
====================================================================================================

不要从 600 行文件第一行硬啃。每次带着一个问题阅读。

第 1 站：最小状态图
====================================================================================================

运行 ``examples/01_minimal_stategraph.py``，回答：State 是什么，节点返回的是完整状态还是局部更新，条件边在何时运行？

然后看：

* ``graph/state.py``
* ``graph/builder.py`` 中 ``add_node`` 和 ``add_conditional_edges`` 部分
* ``graph/routes.py``

第 2 站：订单工具循环
====================================================================================================

运行 ``examples/06_controlled_tool_loop.py``，沿着：

``initialize → plan → execute → plan → finalize``。

重点回答：模型为什么不能直接调用 Repository？工具白名单在哪里检查？循环如何停止？

第 3 站：FAQ 与 RAG
====================================================================================================

运行 ``examples/04_grounded_faq_rag.py``，再按顺序读：

``chunking.py → embeddings.py → retriever.py → reranking.py → generation.py → nodes/faq.py``。

重点回答：阈值、范围门、重排和证据判断分别拦截什么问题？

第 4 站：退货暂停与恢复
====================================================================================================

运行 ``examples/07_human_approval_return.py``，看 ``nodes/returns.py`` 和 API 的审批接口。

重点回答：第一次调用在哪里停？什么内容进入 Checkpoint？恢复为什么必须使用原 thread_id？审批前哪张业务表保持不变？

第 5 站：三种数据库后端
====================================================================================================

先运行 SQLite 恢复示例，再看 PostgreSQL Compose。关注 Repository 协议和实现如何替换，而不是先研究每条 SQL。

第 6 站：控制台和调试轨迹
====================================================================================================

打开 ``http://127.0.0.1:8000/console/``，完成一次订单请求，再用开发角色读取 Checkpoint。
把页面每一步对应到 ``builder.py`` 中的节点。

第 7 站：评测实验
====================================================================================================

按 24 → 25 → 26 → 27 → 28 → 29 阅读实验文档。每一步只回答四个问题：

1. 上一步暴露了什么失败？
2. 本步只改变了哪个变量？
3. 开发集如何选择候选？
4. 锁定集是否通过，结论边界是什么？

建议的复述练习
====================================================================================================

读完每一站后关闭文档，用 90 秒回答：

* 用户输入从哪个文件进入？
* 这一站最重要的状态字段是什么？
* 失败时系统走哪里？
* 有哪个测试或实验能证明你的说法？

能不看答案说清楚，才算真正掌握。
