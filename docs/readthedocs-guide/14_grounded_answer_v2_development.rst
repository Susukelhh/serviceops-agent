21. Grounded Answer v2开发：把模型问题与评测器问题分开（项目第35步）
====================================================================================================

第34步首次 ``10/25（40%）`` 继续原样保留。私有诊断证明，这15道失败题并不是同一种问题：

* 5道存在真实回答遗漏、条件丢失或无依据类推；
* 9道主要是机械同义词漏判或金标范围过严；
* 1道正确拒答携带草稿引用，但生产FAQ节点最终会清空引用。

因此当前重点不是继续调整Qdrant、Embedding或RRF。多数失败正例已经找到并引用正确证据，瓶颈在答案
完整性和评分有效性。

零费用重放
====================================================================================================

开发评分器 ``grounded-success-development-audit-v1.1`` 排除4条范围过严事实、补充版本化同义表达，并
按照生产系统最终可见状态清理拒答引用。它重放第34步已经保存的原答案，不调用任何模型：

.. code-block:: powershell

   uv run python examples/35_grounded_answer_v2_development.py --confirm-revealed-regression --replay-latest-v1-diagnostic

本机实测结果：

.. code-block:: text

   端到端有据回答成功率：20/25 = 80.00%
   红线失败题：1条
   质量门：FAIL

20/25只能叫已揭晓开发重评分，不能替换首次40%。知识库没有明确给出清灰、换硅脂的价格和次数时，模型
仍自动推断需要付费，真实红线没有因为修改评分器而消失。

Prompt v2
====================================================================================================

旧提示保留为 ``GROUNDED_ANSWER_SYSTEM_PROMPT_V1``，候选指纹仍是
``d1fd2d5ba3f235ee4f8b259472dc81e19237430e9792e439ef4207fb0974cde7``。

新提示v2具有独立指纹
``4e2ed3da452c0a41e3b57181fb7036073754333444e673c96f0fa57623f758cb``，主要约束：

* 覆盖用户明确询问的全部子问题；
* 保留“可能”“审核确认后”“约定范围内”等条件；
* 不用一般保修或一般售后规则推断具体服务、价格、次数和资格；
* 任一子问题缺少直接证据时拒答，并返回空引用。

真实开发候选
====================================================================================================

下面的命令会再次产生约4次Embedding和最多25次聊天调用，只能由项目所有者本人运行：

.. code-block:: powershell

   uv run python examples/35_grounded_answer_v2_development.py --confirm-revealed-regression --confirm-paid-api --write-private-diagnostics

.. warning:: 这不是新盲测

   即使Prompt v2在这25题上达到100%，也只能说明通过已揭晓开发回归。真正晋级必须使用从未参与提示、
   评分器或金标调整的全新v2密封集。

真实结果与逐题变化
====================================================================================================

本机真实运行得到 ``20/25（80%）``、0条红线、开发Gate PASS，使用4次Embedding请求和25次聊天调用。
公平比较必须给v1与v2使用同一个v1.1开发评分口径：v1原回答也是20/25，但有1条无依据自动回答红线，
所以Gate FAIL；v2总分没有增加，但把红线降到了0。

逐题看，v2修好3题，也有3题发生表达退化。剩余5题经私有人工复核后分为：3题模型确实漏答、1题
确定性同义表达漏判、1题金标范围过严。因此本步最准确的结论是“开发集安全拒答得到改善”，不是
“未知样本准确率从40%提升到80%”。脱敏结果位于
``data/evaluation/results/grounded_answer_v2_development_result.json``。

面试表达
====================================================================================================

不要说“把40%优化到了80%”。更准确的说法是：首次严格盲测为40%；私有诊断发现评分假失败与真实模型
风险混在一起；同一批原回答经审计口径零费用重放为80%，但仍有红线；Prompt v2在同口径下也是80%，
但红线降为0并通过开发Gate。这个变化证明安全拒答改善，不证明未知样本效果，最终仍需全新密封集。
