运行命令
====================================================================================================

.. code-block:: powershell

   uv run python examples/36_grounded_answer_v2_sealed.py

.. code-block:: powershell

   uv run python examples/36_grounded_answer_v2_sealed.py --confirm-sealed

.. code-block:: powershell

   uv run python examples/36_grounded_answer_v2_sealed.py --confirm-sealed --confirm-paid-api

真实运行预计约4次Embedding请求和最多30次聊天调用。第一次不要添加 ``--regression``；首次公开结果采用
独占写入，后续复跑不能覆盖，也不能再称新盲测。

结果边界
====================================================================================================

成功率至少80%且红线为0，才说明Prompt v2通过未知题验收。如果失败，必须保留结果并把题集转为开发集；
修复后的下一次未知验证需要建立新的v3密封集。

这证明第35步开发集上的0红线没有泛化，Prompt v2不能晋级生产。首次结果已经冻结，后续同题运行只能

.. code-block:: powershell

   uv run python examples/36_grounded_answer_v2_sealed.py --confirm-sealed --confirm-paid-api --regression --write-private-diagnostics

该命令只用于根因定位，不能覆盖或改写首次43.33%的结论。

REGRESSION人工审计
====================================================================================================

REGRESSION自动评分为15/30、1条红线。逐题读取本机私有答案后发现，15道自动失败中有6道短语匹配
漏判、5道金标范围过严、1道两类问题并存、1道拒答引用与生产最终状态不一致、1道知识缺口标签错误，
真正剩余的端到端错误只有1道：范围门把“客服能否索要密码和验证码”的安全咨询误判成凭据提取。

人工语义复核为29/30，但它不是自动Gate，也不是新盲测，不能覆盖首次13/30。这个结果说明优先级应该从
“继续调Prompt”改为“先修评测器和范围门”。脱敏审计位于
``data/evaluation/results/grounded_answer_v2_sealed_regression_audit.json``。
