====================================================================================================
17. 大白话术语表
====================================================================================================

.. glossary::

   Agent
      能根据当前状态选择下一步动作，并可能调用工具、观察结果、暂停或结束的系统；不等于普通聊天机器人。

   State
      一次流程随身携带的结构化办事单。

   Node
      流程图中的一个办事步骤，只完成一类明确任务。

   Edge
      节点之间的路线。条件边会根据 State 决定去哪。

   Checkpoint
      某个节点边界的流程快照，用于回看和恢复，不等同业务数据库。

   Thread ID
      一条可持续流程的唯一编号，暂停和恢复必须使用同一个编号。

   Tool Calling
      模型输出结构化的工具选择和参数，后端验证后执行预先注册的函数。

   RAG
      回答前先检索外部知识，把证据交给模型，再约束它基于证据回答。

   Chunk
      从长文档切出来的小段，便于索引和检索。

   Overlap
      相邻 Chunk 重复保留的内容，避免一句话正好被切断。

   Embedding
      把文本变成数字向量，使语义接近的内容能按距离搜索。

   Qdrant
      保存和检索向量的独立服务；Compose 中两只 Agent 共用持久化 Collection。

   BM25
      关注关键词稀有程度和出现情况的检索方法；新版会独立搜索全部知识切片。

   RRF
      Reciprocal Rank Fusion，倒数排名融合；不强行相加两种不同单位的分数，而是合并两张名次榜。

   Rerank
      对第一轮召回的候选重新排序。候选里没有正确文档时，重排救不回来。

   Grounding
      要求答案建立在给定证据上，并能指出来源。

   Hallucination
      模型生成听起来合理、实际没有证据或不真实的内容，中文常称幻觉。

   Human-in-the-loop
      在高风险步骤让流程暂停，由人类明确决定后再继续。

   Idempotency
      同一个请求重复执行不会重复产生业务结果。

   Transaction
      一组数据库操作要么一起成功，要么一起失败。

   Outbox
      和业务记录同事务保存的“待发送事件箱”，之后由任务可靠投递。

   JWT
      带签名和过期时间的身份凭证。

   RBAC
      按角色分配权限，例如客户、审批人、审计员和开发者。

   Trace
      关联一次请求全部处理阶段的追踪编号。

   Docker Image
      包含代码和运行环境的只读软件包模板。

   Container
      镜像真正运行起来的一个实例。

   CI
      每次代码变化后，在干净环境自动运行检查和测试。

   Development Set
      可以反复查看并用于选方案的开发题集。

   Holdout Set
      配置冻结后才揭晓的一次性验收题集，用于检查是否只对开发题有效。

   MCP
      连接模型应用与外部工具、资源的标准协议；它不自动提供业务授权、幂等和人工审批。
