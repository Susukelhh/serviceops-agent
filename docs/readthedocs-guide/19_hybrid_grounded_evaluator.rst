第40步：分层端到端评测器
====================================================================================================

第40步把通过人工校准的语义Judge接入端到端裁决，但不给它覆盖安全规则的权限。确定性规则先检查红线、引用、
证据和无依据回答；只有唯一失败为 ``required_fact_missing`` 时才进入语义复核。Judge的FAIL、NEEDS_REVIEW
或缺失结论全部失败关闭。

为什么不能让Judge决定一切
====================================================================================================

Judge擅长理解同义改写，却仍是概率模型。伪造引用、禁止事实和无依据回答必须由确定性代码零容忍拦截。
Judge只是语文复核员，不是安全主管。

回放读取第38步20/30正式结果、第39步20/20校准结果和10条脱敏Judge结论，全部使用SHA和候选指纹验证。

====================================================================================================

PyCharm Script path填写 ``D:\serviceops-agent\examples\40_hybrid_grounded_evaluator_replay.py``，Working
directory填写 ``D:\serviceops-agent``，Parameters留空。命令行：

.. code-block:: powershell

   uv run python examples/40_hybrid_grounded_evaluator_replay.py

测试覆盖红线优先、混合失败禁止升级、FAIL/NEEDS_REVIEW/缺失结论失败关闭、来源SHA和幂等结果保护。
