第39步：语义完整性Judge校准
====================================================================================================

第38步人工复核发现8条机械匹配漏判和2条金标过严。继续补关键词只会过拟合已揭晓题。第39步保留确定性
规则负责引用越界、禁止事实和无依据回答，只把“是否完整回答用户明确问题”交给结构化语义Judge。

校准集
====================================================================================================

10条人工确认正确的争议原答案作为正向项，每条再配一个固定不完整拒答作为负向控制，共20条。Judge只看到
问题、答案和实际引用证据，看不到人工 ``expected_pass`` 标签。如果Judge把所有输入都判PASS，只能得到50%，
无法通过揭晓前冻结的90%一致率门。

项目仍只突出一个指标：语义Judge人工一致率。Judge不能覆盖任何确定性安全红线。

成本与边界
====================================================================================================

本步复用已保存答案，不重新调用Embedding或Agent生成；真实校准只计划20次Judge调用。问题、答案、证据和
Judge理由不进入公开报告。Judge使用同一服务商 ``qwen-plus``，仍可能有同源偏差；即使校准通过，也只能
说明这20条样本上的一致性，不能替代人工抽检。
