====================================================================================================
11. 控制台：把工程过程展示出来
====================================================================================================

页面展示什么
====================================================================================================

浏览器控制台不是另一个模拟 Demo，它调用真实 FastAPI 接口并展示：

* Agent 回答、意图、工具结果和 RAG 引用；
* 从认证、分类、检索、规划、工具、审批到响应的公开事件时间线；
* 退货流程真正暂停后才出现的审批卡；
* 开发模式下按时间排序的 Checkpoint 和公开 State 变化；
* API、数据库、Checkpointer、Outbox 和审计仓储的就绪状态。

为什么不展示隐藏推理
====================================================================================================

模型内部生成的隐藏推理文字不是可靠审计证据，也可能包含敏感信息或容易被误解的草稿。
项目展示的是可以验证的工程事实：节点名称、输入输出 Schema、工具调用、证据引用、状态变化和审批决定。

可以把二者理解为：隐藏推理像一个人的脑内念头；工程轨迹像窗口叫号、签字单和数据库回执。企业审计应该依靠后者。

Checkpoint 调试接口如何脱敏
====================================================================================================

后端不直接暴露 Checkpointer 私有表，而是通过 LangGraph 的状态历史 API 读取快照，然后使用字段白名单转换。
用户身份细节、Token 编号、幂等键、工具指纹、Outbox 编号和异常原文不会返回。

接口只在 development/test 环境开放；production 固定返回 404。开发角色也不会自动获得聊天、审批或审计权限。

前端安全
====================================================================================================

* 动态文字使用 ``textContent``，避免把模型输出当 HTML 执行。
* Token 只保存在当前页面内存和密码输入框，不写浏览器长期存储。
* 页面设置 CSP、禁止缓存、禁止 MIME 猜测和 iframe 嵌入。
* 调试大屏只是改变浏览器布局，不修改 State 或权限。
