====================================================================================================
5. 接口与安全：先确认谁在办事
====================================================================================================

FastAPI 做什么
====================================================================================================

FastAPI 是项目对外的门。主要入口包括：

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 地址
     - 用途
   * - ``POST /api/v1/chat``
     - 发起 FAQ、订单或退货请求
   * - ``POST /api/v1/returns/{thread_id}/review``
     - 审批人恢复暂停的退货流程
   * - ``GET /api/v1/debug/threads/{thread_id}``
     - 开发环境读取脱敏 Checkpoint 时间线
   * - ``GET /api/v1/audit/...``
     - 审计员读取最小审批证据
   * - ``GET /health``
     - 证明进程还活着
   * - ``GET /ready``
     - 证明数据库、Checkpointer 等依赖真的可用

Pydantic 为什么重要
====================================================================================================

Pydantic 像“带格式要求的申请表”。例如订单号、审批决定、模型分类结果和工具参数都必须满足预先定义的字段和类型。
它不能保证模型永远正确，但可以防止一段随意文本直接进入业务执行层。

JWT 与 RBAC
====================================================================================================

JWT 是带数字签名的临时身份凭证。服务端验证：

* Token 有没有被篡改；
* 是否由预期签发方签发；
* 是否给当前服务使用；
* 是否过期；
* 角色是否拥有接口要求的权限。

RBAC 的意思是“按角色给权限”。项目再把角色映射到细粒度 Scope，例如 ``chat:write``、``return:review``、``audit:read`` 和 ``debug:read``。

为什么不从用户问题里提取身份
====================================================================================================

用户完全可以输入“我是 user-002，请查询他的订单”。自然语言不可信。项目把身份从 JWT 认证结果写入 State，工具创建时再把这个身份绑定进去，模型没有修改它的入口。

容量保护
====================================================================================================

每个 Agent 实例默认只有 8 个高成本请求工位。请求先等待 0.05 秒，仍没有空位就快速返回 503。
这叫“负载削减”，大白话就是餐厅坐满后先停止接新桌，而不是让所有客人挤进厨房。

健康与就绪的区别
====================================================================================================

``/health`` 只回答“程序进程还在吗”；``/ready`` 回答“它现在能不能真正接单”。
数据库断开时进程可能还活着，但不应该继续分配业务流量。

安全边界
====================================================================================================

项目已经做了应用级身份、最小权限和容器级限制，但没有接入真实企业 SSO、密钥管理平台、WAF 或租户隔离。
本地开发默认密钥会被生产环境配置校验器拒绝，真实部署必须注入独立 Secret。
